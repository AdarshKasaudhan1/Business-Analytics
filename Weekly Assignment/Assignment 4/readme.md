Experiment No.: 4

Data Cleaning using Power Query

Problem Statement
 A cafe company has received customer transaction data containing missing values, blank cells, null values, and inconsistent entries. The objective is to clean and prepare the dataset using Power Query so that it becomes accurate, consistent, and ready for business analysis.

Learning Outcomes

Through this experiment, I learned:

•	Importing CSV datasets into Power BI

•	Using Power Query for data cleaning

•	Handling null, blank, and missing values

•	Replacing inconsistent entries

•	Removing errors and validating data quality

•	Preparing datasets for accurate business analytics
